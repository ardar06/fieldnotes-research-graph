# Third-party notices

## Sherlock Project site metadata

`backend/app/resources/sherlock_sites.json` is a filtered subset of the Sherlock Project's public site metadata (`sherlock_project/resources/data.json`), pinned from commit `c588d7c8b476df9f9c84912a05d1430fb8cdcdae` (2026-11-01). The filter retains HTTPS profile URL templates with status-code checks, excludes NSFW sites and non-HEAD request methods, and does not include Sherlock's probing implementation.

Source: https://github.com/sherlock-project/sherlock
